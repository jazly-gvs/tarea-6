# Tarea 6 - Gestión y Control de Gastos

Este proyecto consiste en una aplicación de gestión de gastos desarrollada exclusivamente con JavaScript vanilla, cumpliendo con las restricciones de estructuras de control tradicionales y bucles nativos solicitados en la rúbrica.

## 🚀 Ejecución del Proyecto
Para ver el funcionamiento del programa:
1. Abra el archivo `index.html` en el navegador Chrome.
2. Abra las Herramientas de Desarrollador (**F12**).
3. Seleccione la pestaña **Consola (Console)** para visualizar las tablas estructuradas, el informe corporativo JSON y las pruebas de errores controladas.
